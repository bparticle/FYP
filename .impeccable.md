## Design Context

### Users
Crypto art collectors and NFT community members; primarily on desktop but mobile-aware. Context: browsing during or after NFC Lisbon (June 2026), arriving from Objkt, Twitter/X, or the artist's socials. Goal: understand the work, decide whether to mint/collect, find the mint links.

### Brand Personality
Raw · Liturgical · Deadpan. The piece is an altarpiece for the algorithm — it takes social media seriously as subject matter but treats the mini-site with the solemn restraint of a museum exhibition page. No hype, no marketing language. The visual language is Functional Anti-Design: things look designed *against* convention.

### Aesthetic Direction
- **Theme**: Light (white gallery wall + salmon blush ground). Not dark — gallery, not nightclub.
- **Typography**: Courier New (mono) for everything except ONE display moment — the FYP wordmark in Arial Black. That discipline is sacred to the project.
- **Palette**: Ink `#222`, paper `#fff`, blush `#F7D9D2`. The only accent is functional default link blue `#0000EE` — kept deliberately "wrong." No brand colors, no gradients, no glassmorphism.
- **Structure**: Hard borders, hard offset box-shadows (no soft/blurred shadows), zero border-radius, bimodal whitespace. Museum caption typography throughout.
- **References**: White-cube gallery catalogues, museum object labels, brutalist editorial print design. Anti-reference: anything that looks like a Web3 hype site, gradient-heavy NFT landing page, or generic SaaS.

### Design Principles
1. **Every element earns its weight.** If it doesn't serve the work or the collector, cut it.
2. **Ink speaks loudly — use it sparingly.** The heavy ink blocks (links list, panel cards) are intentional anchors. New elements should read lighter unless they're anchors too.
3. **Mono discipline.** Courier New for all body/UI copy. Arial Black only for the FYP wordmark. Never deviate.
4. **No softness.** No rounded corners, no blurred shadows, no gradients. Hard edges only.
5. **Colophon mentality for secondary info.** Socials, notes, credits belong in the quiet lower register — footnote weight, not headline weight.
